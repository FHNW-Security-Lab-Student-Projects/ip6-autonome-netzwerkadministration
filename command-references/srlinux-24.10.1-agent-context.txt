SR LINUX v24.10.1 READ-ONLY COMMAND REFERENCE
Nokia 7220 IXR / 7250 IXR / 7730 SXR
All commands are read-only (show / info from state / ping / traceroute).

================================================================================
OUTPUT MODIFIERS (append to any command)
================================================================================
| as json          output as JSON
| as yaml          output as YAML
| grep <pattern>   filter lines
| head <N>         first N lines
| tail <N>         last N lines
| count            count lines
| no-more          disable pager

================================================================================
DATASTORES
================================================================================
show <x>                  formatted operational view
info /path                raw running config at YANG path
info from state /path     raw operational state at YANG path
info detail /path         running config including all defaults

================================================================================
WILDCARDS AND RANGES (24.3+)
================================================================================
show interface ethernet-1/{1..5}           range
show interface ethernet-1/{1,3,5}          list
show interface ethernet-1/*                wildcard
info from state /interface[name=ethernet-1/*]/oper-state

================================================================================
INTERFACE NAMING
================================================================================
ethernet-1/<port>           data port          e.g. ethernet-1/1
ethernet-1/<port>/<bkout>   breakout port      e.g. ethernet-1/3/1
mgmt0                       management port
lo<N>                       loopback           e.g. lo0
lag<N>                      link aggregation   e.g. lag1
irb<N>                      integrated routing/bridging  e.g. irb0

================================================================================
SYSTEM & PLATFORM
================================================================================
show version                         hostname, chassis type, SW version, last boot, total/free memory
show platform chassis
show platform environment            all modules: control, linecards, fans, PSUs, temperature
show platform control * detail       CPU, memory, disk, SW version per control module
show platform redundancy             CPM redundancy state
show platform linecard * detail      linecard hardware and temp detail
show platform fabric * detail        fabric module detail (chassis-based platforms)
show platform fan-tray               fan tray status
show platform power-supply           power supply status

NOTE: There is no "show system cpu", "show system memory" or "show system uptime".
      CPU and memory are read from "show platform control A detail" or info from state paths below.

STATE PATHS — SYSTEM / PLATFORM
/system/information                             hostname, SW version, last-booted
/platform/control[slot=A]/cpu[index=all]/total/instant
/platform/control[slot=A]/memory/utilized
/platform/control[slot=A]/memory/free
/platform/chassis

================================================================================
INTERFACES
================================================================================
show interface                   all UP interfaces with subinterface and IP summary
show interface brief             tabular all interfaces (admin-state, oper-state, speed, type)
show interface all               all interfaces including down with down-reason
show interface <intf>            e.g. show interface ethernet-1/1
show interface <intf> detail
show interface <intf> statistics  in/out octets, packets, error frames, discarded frames
show interface <intf>.<idx>      specific subinterface  e.g. ethernet-1/1.0
show interface <intf> transceiver  optics / SFP wavelength, Tx/Rx power, temp

================================================================================
OSPF
================================================================================
PREFIX: show network-instance <ni> protocols ospf instance <inst>

  neighbor             all neighbors with state, area, and uptime
  database             full LSDB
  database summary     LSDB counts by LSA type
  route-table          OSPF computed routes
  interface            OSPF interfaces, hello/dead timers, DR/BDR
  statistics           OSPF PDU counters

STATE PATHS — OSPF
/network-instance[name=<N>]/protocols/ospf/instance[name=<I>]/neighbor
/network-instance[name=<N>]/protocols/ospf/instance[name=<I>]/area[area-id=<A>]/interface[interface-name=<IF>]/neighbor
/network-instance[name=<N>]/protocols/ospf/instance[name=<I>]/statistics

================================================================================
IS-IS
================================================================================
