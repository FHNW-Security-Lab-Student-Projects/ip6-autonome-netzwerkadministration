SR LINUX v24.10.1 READ-ONLY COMMAND REFERENCE
Nokia 7220 IXR / 7250 IXR / 7730 SXR
All commands are read-only (show / info / ping / traceroute). No config or tools commands.

================================================================================
OUTPUT MODIFIERS (append to any command)
================================================================================
| as json          output as JSON
| as yaml          output as YAML
| grep <pattern>   filter lines
| head <N>         first N lines
| tail <N>         last N lines
| count            count lines
| no-more          disable pager

BGP
================================================================================
PREFIX: show network-instance <ni> protocols bgp

  (no args)                         overall BGP instance state
  summary                           neighbor table with Rx/Active/Tx counts
  statistics                        BGP PDU and update counters
  group <group-name>                peer group config and state

PREFIX: show network-instance <ni> protocols bgp neighbor

  (no args)                         all neighbors with state and uptime
  <peer-ip>                         single neighbor detail
  <peer-ip> received-routes ipv4    IPv4 prefixes received from peer
  <peer-ip> advertised-routes ipv4  IPv4 prefixes advertised to peer
  <peer-ip> received-routes evpn    EVPN routes received from peer
  <peer-ip> advertised-routes evpn  EVPN routes advertised to peer

PREFIX: show network-instance <ni> protocols bgp rib

  ipv4-unicast                      full IPv4 local RIB
  ipv4-unicast prefix <prefix/len>  single prefix detail
  ipv6-unicast                      full IPv6 local RIB
  evpn route-type 1                 EVPN Ethernet Auto-Discovery routes
  evpn route-type 2                 EVPN MAC/IP routes
  evpn route-type 2 mac <mac>       specific MAC
  evpn route-type 3                 EVPN Inclusive Multicast routes
  evpn route-type 5                 EVPN IP Prefix routes
  evpn route-type 5 ip-prefix <p>   specific IP prefix

NEIGHBOR STATE FLAGS: S=static D=dynamic L=LLDP B=BFD-enabled -=disabled *=slow
