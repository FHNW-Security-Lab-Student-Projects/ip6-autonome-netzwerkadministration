SR LINUX v24.10.1 — AGENT CHEAT SHEET (read-only commands)
Nokia 7220 IXR / 7250 IXR / 7730 SXR

For any YANG path not listed here, call search_yang_paths(keyword, domain) instead of guessing.

================================================================================
DATASTORES
================================================================================
show <x>                  formatted operational view
info /path                raw running config at YANG path
info from state /path     raw operational state at YANG path
info detail /path         running config including all defaults

  | as json    | as yaml    | grep <pat>    | head <N>    | no-more
