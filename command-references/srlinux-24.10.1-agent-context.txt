SR LINUX v24.10.1 READ-ONLY COMMAND REFERENCE
Nokia 7220 IXR / 7250 IXR / 7730 SXR
All commands are read-only (show / info from state / ping / traceroute).
Revision: agent-verified — invalid commands removed or moved to KNOWN INVALID section.

================================================================================
OUTPUT MODIFIERS (append to any command)
================================================================================
| as json          output as JSON
| as yaml          output as YAML
| grep <pattern>   filter lines
| head <N>         first N lines
| tail <N>         last N lines
| count            count lines
| no-more          disable pager

================================================================================
DATASTORES
================================================================================
show <x>                  formatted operational view
info /path                raw running config at YANG path
info from state /path     raw operational state at YANG path
info detail /path         running config including all defaults

================================================================================
WILDCARDS AND RANGES (24.3+)
================================================================================
show interface ethernet-1/{1..5}           range
show interface ethernet-1/{1,3,5}          list
show interface ethernet-1/*                wildcard
info from state /interface[name=ethernet-1/*]/oper-state

================================================================================
INTERFACE NAMING
================================================================================
ethernet-1/<port>           data port          e.g. ethernet-1/1
ethernet-1/<port>/<bkout>   breakout port      e.g. ethernet-1/3/1
mgmt0                       management port
lo<N>                       loopback           e.g. lo0
lag<N>                      link aggregation   e.g. lag1
irb<N>                      integrated routing/bridging  e.g. irb0

================================================================================
SYSTEM & PLATFORM
================================================================================
show version                         hostname, chassis type, SW version, last boot, total/free memory
show platform chassis
show platform environment            all modules: control, linecards, fans, PSUs, temperature
show platform control * detail       CPU, memory, disk, SW version per control module
show platform linecard * detail      linecard hardware and temp detail
show platform fabric * detail        fabric module detail (chassis-based platforms)
show platform fan-tray               fan tray status
show platform power-supply           power supply status

NOTE: There is no "show system cpu", "show system memory" or "show system uptime".
      CPU and memory are read from "show platform control A detail" or info from state paths below.
NOTE: "show platform redundancy" is INVALID on fixed-chassis platforms (7220 IXR).
      It only exists on modular chassis with dual CPMs.

STATE PATHS — SYSTEM / PLATFORM
/system/information                             hostname, SW version, last-booted
/platform/control[slot=A]/cpu[index=all]/total/instant
/platform/control[slot=A]/memory/utilized
/platform/control[slot=A]/memory/free
/platform/chassis

================================================================================
INTERFACES
================================================================================
show interface                   all UP interfaces with subinterface and IP summary
show interface brief             tabular all interfaces (admin-state, oper-state, speed, type)
show interface all               all interfaces including down with down-reason
show interface <intf>            e.g. show interface ethernet-1/1
show interface <intf> detail     includes statistics (in/out octets, packets, errors, discards)
show interface <intf>.<idx>      specific subinterface  e.g. ethernet-1/1.0

NOTE: "show interface <intf> statistics" is INVALID — stats are included in detail output.
NOTE: "show interface <intf> transceiver" is INVALID as a show command.
      Use state path below for transceiver/optics data.

STATE PATHS — INTERFACES
/interface[name=<N>]/oper-state
/interface[name=<N>]/oper-down-reason
/interface[name=<N>]/ethernet/hw-mac-address
/interface[name=<N>]/statistics/in-octets
/interface[name=<N>]/statistics/out-octets
/interface[name=<N>]/statistics/in-error-frames
/interface[name=<N>]/statistics/out-error-frames
/interface[name=<N>]/statistics/in-discarded-frames
/interface[name=<N>]/statistics/out-discarded-frames
/interface[name=<N>]/transceiver
/interface[name=<N>]/subinterface[index=<I>]/oper-state
/interface[name=<N>]/subinterface[index=<I>]/ipv4/address
/interface[name=<N>]/subinterface[index=<I>]/ipv6/address

================================================================================
NETWORK INSTANCES
================================================================================
show network-instance                              all NIs with type and oper-state
show network-instance summary                      summary view of all NIs
show network-instance <ni> interfaces              interfaces attached to NI (plural)

ROUTE TABLE
show network-instance <ni> route-table
show network-instance <ni> route-table ipv4-unicast
show network-instance <ni> route-table ipv4-unicast summary
show network-instance <ni> route-table ipv4-unicast prefix <prefix/len>
show network-instance <ni> route-table ipv4-unicast route <prefix/len>
show network-instance <ni> route-table ipv4-unicast route <prefix/len> include-inactive
show network-instance <ni> route-table ipv6-unicast

NOTE: "show network-instance <ni>" with a specific NI name shows a help/usage menu, not detail.
      Use "show network-instance summary" for an overview.
NOTE: "show network-instance <ni> interface" (singular) is INVALID. Use "interfaces" (plural).

NI TYPES: default (ip-vrf), mgmt, <custom ip-vrf>, <custom mac-vrf>

STATE PATHS — NETWORK INSTANCES
/network-instance[name=<N>]/oper-state
/network-instance[name=<N>]/interface
/network-instance[name=<N>]/route-table/ipv4-unicast
/network-instance[name=<N>]/route-table/ipv6-unicast

================================================================================
OSPF
================================================================================
PREFIX: show network-instance <ni> protocols ospf instance <inst>

  neighbor             all neighbors with state, area, and uptime
  database             full LSDB
  database summary     LSDB counts by LSA type
  route-table          OSPF computed routes
  interface            OSPF interfaces, hello/dead timers, DR/BDR
  statistics           OSPF PDU counters

STATE PATHS — OSPF
/network-instance[name=<N>]/protocols/ospf/instance[name=<I>]/neighbor
/network-instance[name=<N>]/protocols/ospf/instance[name=<I>]/area[area-id=<A>]/interface[interface-name=<IF>]/neighbor
/network-instance[name=<N>]/protocols/ospf/instance[name=<I>]/statistics

================================================================================
IS-IS
================================================================================
PREFIX: show network-instance <ni> protocols isis instance <inst>

  adjacency            all adjacencies with state and circuit type

  statistics           IS-IS PDU counters

STATE PATHS — IS-IS
/network-instance[name=<N>]/protocols/isis/instance[name=<I>]/adjacency
/network-instance[name=<N>]/protocols/isis/instance[name=<I>]/interface[interface-name=<IF>]/adjacency
/network-instance[name=<N>]/protocols/isis/instance[name=<I>]/statistics

================================================================================
CONNECTIVITY TESTS (read-only, no state change)
================================================================================
ping <dst-ip>
ping <dst-ip> network-instance <ni>
ping <dst-ip> -c <N> -s <bytes>
traceroute <dst-ip>
traceroute <dst-ip> network-instance <ni>
tcptraceroute <dst-ip>

NOTE: Keyword-style ping options (count <N> size <bytes> interval <sec>) are INVALID.
      Use Linux-style flags: -c (count), -s (packet size).

================================================================================
KNOWN INVALID COMMANDS (do not use)
================================================================================
show system cpu              -> INVALID. Use: show platform control A detail
show system memory           -> INVALID. Use: show platform control A detail
show system processes        -> INVALID. Use: info from state /system/app-management/application[name=*]
show system uptime           -> INVALID. Use: show version (shows Last Booted timestamp)
show platform redundancy     -> INVALID on fixed chassis. Only valid on modular chassis with dual CPMs.
show interface <intf> statistics         -> INVALID. Use: show interface <intf> detail
show interface <intf> transceiver        -> INVALID. Use: info from state /interface[name=<N>]/transceiver
show network-instance <ni> interface     -> INVALID (singular). Use: show network-instance <ni> interfaces
show network-instance <ni> dhcp-relay    -> INVALID. Use: info from state /network-instance[name=<N>]/dhcp-relay
show arpnd neighbor-entries              -> INVALID. Use: show arpnd neighbors
show system network-instance ethernet-segments -> INVALID. Use: info from state /system/network-instance
show system lldp statistics              -> INVALID. Use: info from state /system/lldp
show bfd session                         -> INVALID. Use: info from state /bfd
show bfd session all                     -> INVALID. Use: info from state /bfd
show bfd summary                         -> INVALID. Use: info from state /bfd
show qos interface <intf>                -> INVALID. Use: info from state /interface[name=<N>]/subinterface[...]/qos
show mirroring mirror-instance           -> INVALID. Use: info from state /mirror-instance
ping <dst> count <N> size <B>            -> INVALID keyword syntax. Use: ping <dst> -c <N> -s <B>
