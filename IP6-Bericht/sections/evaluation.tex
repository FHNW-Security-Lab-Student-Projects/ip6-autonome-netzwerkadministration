\section{Evaluation}
\label{sec:evaluation}

This section reports the measurements from the experiments of \Cref{sec:experiments},
interprets them and states the limits of the setup. One caveat applies to everything: the test
lab is small, with four SR Linux nodes, four clients and only one injected fault at a
time. Additionally, each problem is described by only one open prompt. There is no real human interacting (giving directions or generally more information)
with the agent system. The results show what the system can do in such an environment.
