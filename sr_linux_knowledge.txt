SR LINUX v24.10.1 CONFIGURATION REFERENCE
Nokia 7220 IXR / 7250 IXR / 7730 SXR
All commands are configuration commands (set / delete / commit / discard / info / diff).
Revision: agent-verified

================================================================================
CRITICAL: SR LINUX CLI IS NOT CISCO / JUNIPER / ARISTA
================================================================================
NO "interface GigabitEthernet", NO "ip address", NO "no shutdown"
NO JunOS-style "edit", NO Arista EOS syntax
ALWAYS use SR Linux native set-path syntax as documented below.

================================================================================
CONFIGURATION MODE
================================================================================
enter candidate          enter candidate datastore (required before any set)
set / <path> <k> <v>     configure a parameter
delete / <path>          remove a config node
diff                     show diff between candidate and running
commit now               apply candidate to running
commit save              apply and persist to startup
discard                  abandon candidate changes

INFO COMMANDS (config inspection, no state change)
info                     full candidate config at current context
info flat                flat-path format (pasteable)
info from running        running config at current context
info / <path>            candidate config at specific path
info | as json           output as JSON
info | as yaml           output as YAML

================================================================================
INTERFACE NAMING
================================================================================
ethernet-1/<port>           data port          e.g. ethernet-1/1
ethernet-1/<port>/<bkout>   breakout port      e.g. ethernet-1/3/1
mgmt0                       management port
system0                     loopback / router-id source
lo<N>                       additional loopback e.g. lo0
lag<N>                      link aggregation   e.g. lag1
irb<N>                      integrated routing/bridging  e.g. irb0

================================================================================
INTERFACE CONFIGURATION
================================================================================
set / interface ethernet-1/1 admin-state enable
set / interface ethernet-1/1 description "Link to Router2"
set / interface ethernet-1/1 mtu 9000

SUBINTERFACE — ROUTED (IPv4)
set / interface ethernet-1/1 subinterface 0
set / interface ethernet-1/1 subinterface 0 admin-state enable
set / interface ethernet-1/1 subinterface 0 ipv4 admin-state enable
set / interface ethernet-1/1 subinterface 0 ipv4 address 192.168.1.1/24

SUBINTERFACE — ROUTED (IPv6)
set / interface ethernet-1/1 subinterface 0 ipv6 admin-state enable
set / interface ethernet-1/1 subinterface 0 ipv6 address 2001:db8::1/64

SUBINTERFACE — BRIDGED (mac-vrf attachment)
set / interface ethernet-1/1 vlan-tagging true
set / interface ethernet-1/1 subinterface 10 type bridged
set / interface ethernet-1/1 subinterface 10 vlan encap single-tagged vlan-id 10

SUBINTERFACE — BRIDGED UNTAGGED
set / interface ethernet-1/1 vlan-tagging false
set / interface ethernet-1/1 subinterface 0 type bridged

NOTE: VLAN encapsulation is a property of the interface/subinterface pair.
      There is no vlan node under network-instance bridge-table.

LOOPBACK / SYSTEM INTERFACE
set / interface system0 admin-state enable
set / interface system0 subinterface 0
set / interface system0 subinterface 0 ipv4 admin-state enable
set / interface system0 subinterface 0 ipv4 address 10.0.0.1/32

LAG
set / interface lag1 admin-state enable
set / interface lag1 lag lag-type lacp
set / interface ethernet-1/1 ethernet aggregate-id lag1

================================================================================
NETWORK INSTANCE CONFIGURATION
================================================================================
NI TYPES: default  |  ip-vrf  |  mac-vrf

CREATE ip-vrf
set / network-instance vrf-blue type ip-vrf
set / network-instance vrf-blue admin-state enable
set / network-instance vrf-blue router-id 10.0.0.1

CREATE mac-vrf
set / network-instance mac-vrf-1 type mac-vrf
set / network-instance mac-vrf-1 admin-state enable

ATTACH INTERFACE (use subinterface notation <intf>.<idx>)
set / network-instance default interface ethernet-1/1.0
set / network-instance default interface system0.0
set / network-instance mac-vrf-1 interface ethernet-1/1.10

NOTE: Associate subinterface to network-instance AFTER creating the subinterface.
NOTE: Bridged subinterfaces attach to mac-vrf. Routed subinterfaces attach to default or ip-vrf.

================================================================================
STATIC ROUTES
================================================================================
set / network-instance default next-hop-groups group nhg1 nexthop 0 ip-address 192.168.1.254
set / network-instance default static-routes route 0.0.0.0/0 next-hop-group nhg1
set / network-instance default static-routes route 0.0.0.0/0 admin-state enable

================================================================================
BGP CONFIGURATION
================================================================================
set / network-instance default protocols bgp admin-state enable
set / network-instance default protocols bgp autonomous-system 65001
set / network-instance default protocols bgp router-id 10.0.0.1

BGP NEIGHBOR
set / network-instance default protocols bgp neighbor 192.168.1.2 admin-state enable
set / network-instance default protocols bgp neighbor 192.168.1.2 peer-as 65002

BGP GROUP
set / network-instance default protocols bgp group ebgp admin-state enable
set / network-instance default protocols bgp group ebgp peer-as 65002
set / network-instance default protocols bgp neighbor 192.168.1.2 peer-group ebgp

================================================================================
ACL CONFIGURATION
================================================================================
set / acl ipv4-filter filter1 entry 10 match ipv4 source-ip prefix 192.168.1.0/24
set / acl ipv4-filter filter1 entry 10 action accept
set / acl ipv4-filter filter1 entry 20 action drop

ATTACH TO INTERFACE
set / interface ethernet-1/1 subinterface 0 acl input ipv4-filter filter1

================================================================================
COMMON MISTAKES
================================================================================
WRONG — Cisco IOS syntax:
  interface GigabitEthernet0/0
   ip address 192.168.1.1 255.255.255.0
   no shutdown

CORRECT — SR Linux syntax:
  set / interface ethernet-1/1 admin-state enable
  set / interface ethernet-1/1 subinterface 0
  set / interface ethernet-1/1 subinterface 0 ipv4 admin-state enable
  set / interface ethernet-1/1 subinterface 0 ipv4 address 192.168.1.1/24
  set / network-instance default interface ethernet-1/1.0

================================================================================
BEST PRACTICES
================================================================================
1. enter candidate before any set command
2. Create interface/subinterface before attaching to network-instance
3. Always set admin-state enable on interface, subinterface, and protocol
4. Use diff before commit now to review changes
5. Subinterface association always uses <intf>.<subinterface-idx> notation
6. Bridged subinterfaces -> mac-vrf only; routed subinterfaces -> default or ip-vrf only
